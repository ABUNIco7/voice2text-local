使用说明
第一步：启动本地服务
在终端运行以下命令（需要 Python + faster-whisper）：
pip install faster-whisper
然后运行 python transcribe_server.py（内置服务脚本，自动启动端口8765）

第二步：确保浏览器打开本页面后，状态显示「服务已就绪」

第三步：上传音频/视频文件，点击「开始转换」，等待结果

安全说明：所有文件仅在本地处理，不会上传到任何服务器。
